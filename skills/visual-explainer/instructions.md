# Adaptador nativo de OmniCore

Aplica las instrucciones de `SKILL.md` incluidas como contribución de esta skill.
Los archivos de referencia incluidos describen las salidas TUI y HTML. Las rutas
relativas pertenecen al directorio del paquete indicado en este contexto.
La skill aporta instrucciones y recursos; no concede permisos ni ejecuta scripts
al descubrirla o activarla. Respeta las herramientas disponibles y la petición
actual del usuario.
