Fecha: 2026-10-08. Worktree codex/tui-markdown-polish, base bb664cb.

ALCANCE IMPLEMENTADO
- changedFiles: un efecto de journal por ToolCallId de la sesión, con ownership
  de Run/Lane/Task/Turn/Execution. No consulta Git ni archivos actuales.
- filesystem.write/patch publican evidencia opcional de postimagen exacta en CAS
  Sensitive. ToolCallSucceeded v2 añade AfterStateRef; v1 mantiene null.
  Bytes transitorios del executor no se serializan ni regresan al modelo.
- Pre/postimágenes verificadas: hash, tamaño, tipo, contenido, encoding y hashes
  esperados de reconciliación. Referencias raíces del journal conservadas por GC.
  Secretos, tamaño excesivo o evidencia ausente/corrupta hacen el preview no
  disponible, nunca preimagen vacía ni reversibilidad ficticia.
- Captura opcional no convierte una escritura ya aplicada en fallo.
- DiffPreview por Enter abre el efecto seleccionado, no cambios posteriores;
  muestra contexto, altas/bajas, finales de línea y límite parcial explícito.
  Contadores usan FileVersion.ChangedLines; no se anuncian como distancia LCS.
  Compacto: último efecto por path/Lane. Expandido: efectos anteriores accesibles.
- SidebarConfiguration: YAML User < Project confiable < Workspace local.
  User: <config>/settings.yaml. Project: <repo>/.omnicore/settings.yaml.
  Workspace: <data>/workspaces/<WorkspaceId>/settings.yaml.
  Visibilidad del panel, modos/breakpoints y visible/expanded/priority por widget.
  Errores con ubicación; no se guardan opciones inválidas. Revisión + lease,
  temp único y publicación atómica, preservando otras claves de YAML.
  Sólo comandos de usuario confiables escriben preferencias User/Workspace;
  no modifica providers, budget, credenciales ni políticas de seguridad.
- /sidebar settings: menú por widget y scope; reset, visibilidad, expansión,
  prioridad y modo. /sidebar focus <widget>: inspección incluso si está oculto.
  /sidebar user|workspace <key> <value|reset>: configuración explícita.
- Sesión compacta fija: título/modelo/modo. Run/modelo completo y secuencia en
  diagnóstico expandido. Tabs a ancho medio, stack a ancho amplio, overlay
  estrecho. Colapso por altura preserva TODAS las filas Attention/Error;
  si ni las señales caben, scroll sin inventar una vista vacía.
  F2 persiste apertura; preferencias externas se releen cada dos segundos.

DEFECTOS DETECTADOS Y CORREGIDOS DURANTE IMPLEMENTACIÓN
- Codec de ToolCallSucceeded todavía v1 tras añadir propiedad v2: corregido
  registro; pruebas reejecutadas, sin debilitar assertions.
- Capturar CAS desde continuación async bloqueaba el lease ThreadLocal que
  posee el caller síncrono de ToolRuntime. Captura movida a ese mismo hilo,
  conservando la publicación CAS+journal bajo el lease original.
- Resumen recortado usando Frame.Width=0 antes del primer layout: ahora usa
  ancho responsive calculado. ID Run completo va al detalle desplazable.
- Colapso inicialmente retenía sólo una alerta: ahora conserva todas las
  filas Attention/Error, aunque el panel necesite desplazamiento.
- Header de hunk incluye contexto final; diff conserva líneas vacías,
  distingue cambio exclusivo de finales de línea y archivo nuevo (-0,0).
- Suite general detectó ancho 19 en terminal de 23 columnas, cuyo contrato
  previo exige 20. Corregido sin cambiar la assertion existente; terminales
  menores de 20 siguen acotadas a su ancho real.
- Decode de journal inválido produce snapshot no disponible y
  JournalUnavailable, no un inventario vacío saludable ni mensaje crudo.
- Ruta larga envuelta cambiaba índices visuales: Enter después de una ruta
  envuelta no abría el diff. Reproducción 1 FAIL en
  .tmp-sidebar-p23-wrapping-probe.log; corregido usando coordenadas originales
  de TextView, no InsertionPoint visual. Navegación de headings usa el mismo
  mapeo. La prueba conserva wrapping y exige el diff del último archivo.
Se conservan intentos fallidos locales; no se acreditan como verificaciones verdes.
El primer lote general final registró 3184 casos / 3179 PASS / 1 FAIL / 4 SKIP,
201.122 s, .tmp-sidebar-p23-final-full.log. El fallo fue el ancho 19/20 descrito
arriba; su assertion original se conserva. Los SKIP son permisos de symlink.
