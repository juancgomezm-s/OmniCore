# Acta M9-I — `media.read` end-to-end

**Fecha:** 2026-10-15 · **Estado:** implementación y cableado local verificados; M9 permanece abierto.

## Resultado

Se completó la herramienta `media.read` existente sin duplicar su registro ni los serializadores
multimodales. Una ruta autorizada se lee con límite de bytes, valida el tipo detectado y publica bytes
en CAS como `ImageBlock` tipado. PNG/JPEG se decodifican completamente en Host; WebP comprueba firma,
contenedor y dimensiones, sin afirmar decodificación completa. Una referencia por hash sólo resuelve
si aparece en los eventos de la Session fijada al Run, incluidos adjuntos de usuario, artefactos de
resultado y `AssistantImagesRecorded`; replay usa el snapshot y no reabre la ruta.

La visibilidad requiere capacidad efectiva de entrada de imagen y formato nativo de tool calls. La
frontera clasifica `media.read` como `WorkspaceRead`, bajo los mismos claims, PermissionEngine y techo
de política. El executor Explorer de producción recibe el store CAS del Run. Los serializers OpenAI,
Anthropic y compatible conservan imagen nativa; el compatible agrupa varios resultados de tool antes
del siguiente mensaje de usuario con imágenes. La externalización de texto conserva bloques visuales.
`toolcall.succeeded` expone `resultArtifact` opcional limitado a ID/hash/algoritmo/MIME/tamaño; no
incluye rutas ni bytes. La proyección .NET/TS tolera el campo opcional existente sin cambiar el contrato
de conversación ni añadir preview UI.

El costo de definición se mantiene separado. La sobrecarga de imagen se estima por bytes y puede ser
desconocida para facturación; no se presenta como medida universal de tokens/costo para cada proveedor.
No hay OCR silencioso ni soporte agregado de PDF/audio/video.

## Límite de aceptación

La fixture HTTP es determinista y prueba transporte/wiring, no comprensión visual, inferencia real,
credenciales o facturación. La aceptación live F/F2, inferencia visual real, compatibilidad WebP con
decodificación completa, otros perfiles/proveedores, Linux/macOS/filesystems, idiomas restantes,
procedencia Native/Imported, procesos persistentes/ConPTY y OR5 M8 siguen pendientes. Esta acta no
cierra M9.
