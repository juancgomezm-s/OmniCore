Uso
1. Configurar perfiles User read-only; principal y child con revisión/hash.
2. Run ORQ con UltraCode/adaptive y límites finitos vigentes (no se activa solo).
3. /agents muestra source EventId y selectedItemIds elegibles del principal.
4. /delegate <JSON> publica la cola. Los tokens deben cubrir la cota conservadora
   de la invocación (context capacity + output cap + intentos), no sólo una media.
5. /agent run <DelegationId> ejecuta el primero en cola; /agent cancel <id> cancela.
6. /agents muestra ResultId y summary. /agent accept|reject|rework <id> <ResultId>
   <razón> evalúa; no se aceptan resultados por terminar un worker.
7. /join {"ownerExecutionId":"UUID","kind":"All","members":["UUID"]}
   Quorum requiere requiredCount; Explicit requiere requiredExecutionIds.
   /join cancel <JoinId> abandona la espera explícitamente.
