## Recorrido implementado

TUI y OmniCoder admiten texto largo y adjuntos sin tratar una ruta o base64 completa como prompt.
OmniCoder usa staging de archivos en Electron main, picker/drop y chips removibles; los chunks stdio
permanecen debajo del frame 1 MiB y el Host comprueba orden, tamaño/hash SHA-256 y tipo detectado
antes de crear el original CAS. El manifest se incluye en el payload firmado de M9-D; referencias
CAS no otorgan lectura de rutas. El cliente consume adjuntos sólo tras ACK `Accepted` y mantiene el
borrador ante rechazo.

El TUI mantiene Ctrl+V y selector de archivos/ruta y ahora expone `/paste` como acción explícita de
la línea de comandos. Windows Terminal tiene una acción propia de Ctrl+V que puede interceptar la
tecla antes del proceso CLI ([documentación oficial](https://learn.microsoft.com/en-us/windows/terminal/customize-settings/actions));
la alternativa no cambia preferencias del usuario. El test de conversión CF_DIB acredita el helper
acotado, no la recepción de clipboard real dentro de Terminal. Esa aceptación interactiva está
pendiente.

La extracción implementada cubre UTF-8 estricto, Markdown, CSV, JSON, PDF con PdfPig y DOCX/OOXML.
Los límites son 16 MiB por archivo, 100 páginas PDF, 200.000 caracteres extraídos y expansión DOCX
acotada; texto derivado sensible conserva identidad/versión de extractor en CAS, enlazado desde el
original. Antes de CAS se rechazan secretos en texto extraíble. PDF sin texto embebido se entrega
sin texto derivado; no se ejecuta OCR.

Las imágenes admitidas son PNG, JPEG y WebP. MIME se detecta de los bytes; el Host valida firma,
estructura mínima de header, dimensiones y máximo de píxeles, no decodifica completamente todos los
streams comprimidos. WebP VP8L no está soportado (VP8/VP8X sí). Por ello un stream corrupto con
header coherente puede llegar al provider y ser rechazado allí; no se afirma validación integral de
imagen. Se requiere modalidad de entrada del perfil efectivo y representación del dialecto real;
`media.read` lee rutas sólo tras autorización normal de filesystem y snapshot CAS. Native tool
calling no se usa como sustituto de capacidad visual.

El materializador añade imagen y documentos tipados al `ModelRequest`, conserva adjuntos en replay,
verifica integridad de blobs binarios y preserva referencias durante GC. Los costos de imagen son
reservados/estimados, nunca anunciados como tokens medidos. Si una modalidad no está disponible,
Core rechaza antes de la admisión/run y el borrador se conserva. La ruta TUI in-process sigue
existiendo; el callback de preadmisión queda dentro de Host para respetar la frontera de ensamblados.
