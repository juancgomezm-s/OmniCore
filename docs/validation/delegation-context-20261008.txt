NOT the M7 TaskPacket. Immutable copied facts contain item IDs, original kinds and
historical text. Identity and source provenance are typed. No source CAS reference,
parent transcript, System/WorkingState/tools/files/skills/Memory, parent pinning,
permission grant, mode authorization, routing or TaskBudget is transferred.

PrepareDelegationPacket uses the actual canonical parent execution and child Lane,
direct Task lineage and a canonical lane-local source snapshot. An explicit byte
limit is mandatory, capped at 1 MiB; oversized selections are rejected, not silently
truncated. IArtifactPreparationStore applies redaction and returns immutable bytes
without CAS or journal writes; stores without preparation support fail closed.
Cancellation and rejected preflight do not create durable effects. Repreparation
has the same content hash; a recorded delegation packet cannot be replaced.

The command publisher must Publish under IArtifactPublicationLease and append the
exact reference in DelegationCreated. This delivery does not add a new publisher,
command admission path or worker launcher. Tests publish explicit canonical facts
through EventStream under a publication lease; these are record-only fixtures.

CreateDelegationProjection reads only the actual accepted journal record. It
verifies replay, packet format/version/size/integrity/identity, direct parent-child
link, source event/sequence/snapshot and exact selected facts. Unknown JSON fields,
invented content, sensitive/private selection and foreign scope fail closed.
The source cannot predate the parent's canonical start. If its receipt declares
ExecutionId it must match. With a null identity the parent must be the unique
execution ever started in that Lane through the source receipt. Multiple possible
owners are rejected, never inferred from a latest-start cursor. Exact duplicate
start facts do not create another candidate. No execution identity is fabricated.

Lane during context materialization. No manual injection is used in the integration
test. Reopened SQLite/CAS reproduces the selected facts in the actual ModelRequest.
Only the child receives them, and only after acceptance. Cached contributors stop
after canonical failure/return. Multiple active accepted packets for one Lane are
ambiguous and rejected, never merged or chosen by recency. Generic legacy PacketRef
formats are not interpreted as selected-context packets. Ordinary child budget
trimming protects the current child intent/working state.
