Correction
----------
LoadConversation now projects AssistantMessageRecorded into assistant text.
ModelCompleted remains a fallback only for journals without a canonical message
for that Run/Turn. Canonical and usage records no longer duplicate a final answer.
Deduplication is by Run/Turn, not text; identical answers in separate Turns remain
distinct. Existing redaction and conversation budget/compaction boundaries remain.
Only plain chat crosses Runs; this patch does not broaden tool/result replay.
