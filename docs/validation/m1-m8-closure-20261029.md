## Estado de cierre

cerrado en Windows por [aceptación manual de Juan](m8-windows-user-acceptance-20261029.md).

No se generaron inferencias ni se sustituyó ese modelo por un proveedor remoto.

inspeccionada apunta a la release `9b702820`; no se actualizó ni publicó otra
instalación en esta campaña. La versión instalada y la fuente de main se distinguen.

## Trabajo Linux de esta candidata

- Launcher Strong para procesos batch, stdin exacto/EOF, ambas salidas, exit code,
  timeout, terminación del árbol, rutas de lectura/escritura y red Deny/AllowAll.
- Namespaces bubblewrap, Landlock, seccomp, no-new-privileges y límites nativos.
  El helper se compila desde fuente C y se entrega junto al ejecutable; no se
  versionan binarios generados ni se elimina aislamiento para simular éxito.
- Home temporal privado y archivos públicos NSS de sólo lectura para el SDK.
  NuGet reintentaba `/etc/passwd` indefinidamente sin esos archivos; el probe
  posterior compiló un proyecto real en 3.38 segundos, exit 0, sin nuevos OOM.
- La señal de muerte del padre Linux observa el hilo creador. Se conserva un hilo
  dueño mientras vive el proceso, evitando que retire el ThreadPool un sandbox
  sano. Regresión específica de un caller cuyo hilo termina.
- Los ejecutables instalados fuera de las rutas públicas no exponen sus archivos
  vecinos. Para `dotnet` sólo se montan el ejecutable y los subdirectorios públicos
  del SDK/runtime, sin el almacén de certificados ni las herramientas globales.
  La regresión comprueba que un archivo privado vecino sigue inaccesible.
- Clave de cifrado de credenciales en Secret Service/libsecret, manteniendo el
  archivo cifrado. La clave histórica sólo se retira después de persistirla y
  verificarla en el keyring. Error, conflicto o ausencia de clave no sustituyen
  ni sobrescriben las credenciales existentes. Windows mantiene DPAPI.
- Prueba con keyring/D-Bus propios, perfiles aislados y secretos sintéticos; no se
  desbloquea, lee, migra o elimina la configuración real del usuario en Linux.

La validación local de los componentes Linux pasó. La revisión de Dot y CI de la
candidata siguen pendientes; las pruebas locales no sustituyen esos gates. PTY,
Weak persistente y red AllowList Linux no se añaden en esta candidata. macOS y la
aceptación real local pospuesta conservan sus límites propios.
