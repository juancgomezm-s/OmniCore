# Acta M9-J: contrato nativo Core–OmniCoder

**Estado local:** construido y cableado en los worktrees Core `codex/m9-native-core` y OmniCoder
`codex/m9-native-client`. El bloque cierra su alcance verificable; M9 continúa abierto y no se
afirma paridad funcional total.

## Superficie que queda construida

Core publica `native.catalog` desde el mismo conjunto de capabilities negociadas que `hello`.
El contrato registra 28 queries explícitas, 11 commands y 32 capabilities regulares; incluye las
queries de bootstrap y el scope humano que necesita el supervisor. Las capabilities describen
soporte técnico y no conceden permisos. El catálogo no incluye fuentes falsas ni queries con efecto
de red como `openrouter.credits`. `ui.locale` se traduce sólo al alias wire exacto
`uiLocaleSettings`; el cursor `sessionObservability:<n>` se preserva. Una respuesta superior a 1 MiB
se rechaza como `frame_too_large`, sin truncar ni cerrar la conexión.

El SDK de proceso principal valida el catálogo y entrega DTOs tipados para las vistas de tools,
skills y contexto; las queries genéricas conservan `data: unknown`. También tiene métodos para
comandos genéricos, conversación, acciones humanas, receipts, eventos/replay y artifacts binarios.
El adapter productivo lo usa; submission/cancel/interrupción/modo siguen pasando por callbacks
existentes, grant, capability, sesión/run y prueba HMAC efímera. La prueba HMAC no es el receipt
durable de comando. El renderer recibe sólo vistas allowlisted de tools, skills y contexto, con DTOs
acotados. Tools reflejan elegibilidad del runtime real y no exponen un ejecutor directo. La vista se
invalida ante cambios de workspace/backend/Host/generación/Session/Run/modo/revisión y descarta
resultados tardíos.

Los uploads de adjuntos usan staging en memoria vinculado a la conexión. Begin/chunk/finish no
reservan ni completan receipts durables y no garantizan recuperación tras perder conexión; el
catálogo deja vacío el campo `receipt` en las tres operaciones. La conversación posterior utiliza su
propio flujo durable.
