## Entrega

Se añadió una capability opcional para origen confiable externo sin cambiar stdio 1.0 ni el
command genérico. Electron main confirma la acción y el workspace en diálogo nativo; la prueba
Playwright sustituye el diálogo sólo en el proceso de test aislado. Una clave efímera de 32 bytes
entra al CLI por entorno privado del proceso, se consume y elimina antes de crear el runtime y
se borra de memoria al cierre. Main firma el payload exacto y el Host valida nonce de conexión,
workspace físico, Session/Run y revisión bajo ownership de escritura.

Acciones conectadas a controles reales del Sidecar: registrar input de Plan, seleccionar Plan/Act,
interrumpir y cancelar el Run. El input humano persiste/abre un Run y **no inicia inferencia ni
presenta una respuesta del modelo**. El camino genérico M9-A/B se conserva. Sin bootstrap no se
anuncian capacidades humanas y el Host rechaza commands privilegiados. Proof falso, workspace
distinto, Run distinto, revisión obsoleta, ID/payload alterado y nonce anterior fallan cerrados
sin efectos; recibos consultables no vuelven a ejecutar comandos.

## Límites

El trust boundary es el mismo principal local del SO; HMAC/bootstrap separa renderer y protocolo
genérico, pero no afirma aislamiento contra procesos hostiles del mismo usuario. No hay origen
humano externo genérico ni permiso persistente. No se migró chat/inferencia a Core, no existe
respuesta de modelo ni exactamente-once general. Siguen diferidos `media.read`, push, revisión
multi-OS y procesos persistentes/ConPTY. M9 completo y OR5 no se declaran cerrados.
