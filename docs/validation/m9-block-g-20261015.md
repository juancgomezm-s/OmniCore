# M9-G local validation (2026-10-15)

**Estado:** implementación local en revisión; sin integrar ni publicar. M9 y OR5 M8 continúan abiertos.

## Construcción y alcance

El branch `codex/m9-agent-discovery-core` contiene el catálogo local acotado de fuentes, contributors
de instrucciones/memorias, adaptación de skills portables a `skill.load`, consulta de metadatos por
stdio y comandos de inspección/consentimiento en CLI/TUI. El branch `codex/m9-agent-discovery-coder`
añade el inventario y controles Ask al panel OmniCoder mediante main, preload y bridge. La decisión
se registra en ADR-0053. El workspace de ejecución no se amplía: para cwd anidado sólo se inspecciona
desde el checkout físico Git tras una consulta independiente de confianza; un worktree conserva su
root físico para leer y la identidad Git común sólo para asociar memoria.

El inventario no incluye cuerpos. `skill.load` sigue el flujo autorizado y el request capturado incluye
descripción portable acotada y restricciones, no permisos. Memorias globales requieren Ask; memoria
de proyecto requiere consentimiento enlazado a la identidad exacta. Codex sólo lee los formatos
allowlist declarados; imports remotos, escaping, symlinks/reparse, formatos no admitidos, extensiones
ejecutables e instrucciones de fuentes no confiables quedan inactivos o rechazados con diagnóstico.
