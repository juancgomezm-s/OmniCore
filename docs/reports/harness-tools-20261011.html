Claude Code, ChatGPT / Codex, OpenCode, Pi y OmniCore. Herramientas compatibles por función en la misma fila, con sus diferencias de contrato, disponibilidad y tamaño contextual. La comparación de herramientas conserva su corte histórico; la medición de contexto inicial tiene evidencia independiente.

Qué significa el costo en tokens

R cuenta una definición JSON normalizada con o200k_base: {name,description,input_schema}, JSON compacto UTF-8. Es una medición reproducible de tamaño de referencia, no el costo exacto que factura cada harness o modelo. Los esquemas Pi se reconstruyeron estáticamente desde TypeBox; los de OmniCore se extrajeron de sus constructores C# y se validaron como JSON.

Se excluyen wrappers del proveedor, transformaciones strict, output schemas, instrucciones/guidelines del system prompt, catálogo de skills, llamadas, resultados, imágenes y contexto histórico. Un esquema oculto por modo/política no se inyecta; una tool diferida puede añadir su definición sólo cuando se carga. El prompt cache cambia facturación, no elimina su tamaño contextual. Reutilizar Bash/exec para git o grep no añade una nueva definición.

ND significa que no encontré una cifra oficial por herramienta para esa versión/configuración. No representa cero. Tampoco se asigna cero automáticamente a un plugin sólo porque no se vio su schema.

Dato oficial consultado: para Claude Opus/Sonnet/Haiku 5.5, la documentación muestra 286 tokens de system prompt de tool use con auto/none y 406 con any/tool, cuando hay al menos una herramienta. Es overhead del conjunto/request de la API: no 286 por herramienta ni el total de Claude Code. Se suman nombres, descripciones, esquemas y contenido. Fuente oficial.

Para conocer el costo real por tool: fijar modelo, versión, configuración y conjunto activo; usar el contador del proveedor con/sin esa definición manteniendo el resto idéntico. Los marginales pueden variar por formato y fronteras de tokenización. Esta investigación no inició sesiones de inferencia ni usó cuentas/API privadas.

Fuentes y precisión del corte

Consultado el 11 de octubre de 2026. Claude Code: 46 nombres de tools presentes en su tabla oficial, todos representados arriba. No se equipara un API tool de Anthropic a una tool de Claude Code por compartir marca.

OpenCode documenta nombres como bash y apply_patch; la fuente dev fijada usa shell, patch, subagent y herramientas opencode_*. Se muestran como variantes, sin sumar ambas como herramientas simultáneas de una versión. El desarrollo puede adelantarse a la documentación.

Pi tiene ocho nombres en el registro actual, incluyendo powershell; la fábrica base de coding sigue devolviendo read, bash, edit, write. Lectura/grep/find/ls y PowerShell se pueden seleccionar; no se afirma que las ocho se inyecten por defecto.
